Your first Algebrakit exercise

Pick an exercise: your server creates a session for it and the Algebrakit widget renders it below. Every question type works with the same integration. Try a step, ask for a hint, and watch the learning events arrive.

How this page works
  1. Your server creates a session. server.ts calls client.createSession() with the ID of the chosen exercise and puts the returned session ID in an <akit-exercise session-id="…"> element. Every page load gets a new session.
  2. The page configures the widget, then loads it. AlgebraKIT.config.proxy.url is set before the widget script from widgets.algebrakit.com loads.
  3. The widget talks to Algebrakit through your server. Its calls go to /proxy/algebrakit/* and the server adds your API key, so the key never reaches the browser.
  4. The page listens for learning events. AlgebraKIT.addExerciseListener() reports what the student does, for example each step and whether it was correct.
  5. The solution is the same session in solution mode. Show solution renders the session again with the solution-mode attribute. Back to exercise renders it without, and the student's work is still there.
